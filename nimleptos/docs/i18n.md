# i18n & Localization

NimLeptos provides full-stack internationalization: reactive translations on the client and SSR locale detection on the server.

## Architecture

```
src/nimleptos/i18n/
├── catalog.nim           # MessageCatalog, loadCatalog, mergeCatalogs
├── i18n.nim              # I18nConfig, createI18n, t(), tp(), setLocale, useLocale
├── interpolate.nim       # String interpolation with {placeholder} syntax
├── plural.nim            # ICU plural rules for EN, BG, RU, AR, FR, DE, ES, IT
└── locale_middleware.nim # NimMax middleware for locale detection

(WASM i18n bridge has been archived. See `src/nimleptos/_archive/wasm/i18n_wasm.nim` if needed.)
```

## Message Catalog

Catalogs are loaded from JSON:

```json
{
  "defaultLocale": "en",
  "fallbackLocale": "en",
  "messages": {
    "en": {
      "hello": "Hello",
      "greeting": "Hello, {name}!",
      "items": "{count} items"
    },
    "bg": {
      "hello": "Здравей",
      "greeting": "Здравей, {name}!",
      "items": "{count} елемента"
    }
  }
}
```

```nim
import nimleptos/i18n/catalog

let cat = loadCatalog("locales/app.json")
```

## Reactive Translation

```nim
import nimleptos/i18n/i18n
import nimleptos/reactive/signal

let cfg = createI18n(cat, "en")

# Reactive getter — updates automatically when locale changes
let hello = cfg.t("hello")
echo hello()  # "Hello" or "Здравей" depending on current locale

# With interpolation parameters
let (count, _) = createSignal(5)
let items = cfg.tp("items", proc(): InterpParams =
  {"count": interp.intv(count())}.toTable
)
echo items()  # "5 items"

# Change locale — all reactive getters update
setLocale(cfg, "bg")
echo hello()  # "Здравей"
```

## SSR Translation

```nim
proc pageHandler(ctx: Context) {.async.} =
  let cfg = createI18n(cat, "en")
  let html = buildHtml(cfg):
    el("h1"): t"hello"
    el("p"): tp(cfg, "greeting", proc(): InterpParams =
      {"name": interp.str("World")}.toTable
    )
  ctx.render(html, app, "Home")
```

## Locale Detection Middleware

```nim
import nimleptos/i18n/locale_middleware

let localeConfig = newLocaleDetection("en", @["en", "bg", "fr"])
app.use(localeMiddleware(localeConfig))
```

Detection order (configurable):
1. URL path prefix (`/bg/about` → `bg`)
2. Cookie (`locale=bg`)
3. `Accept-Language` header
4. Default locale fallback

## Pluralization

ICU MessageFormat plural rules:

```nim
import nimleptos/i18n/plural

let msg = parsePluralMessage("one#1 item|other#{count} items")
let form = resolvePlural("en", 5)  # plOther
let text = msg[form].replace("{count}", "5")  # "5 items"
```

Supported locales: EN, BG, RU, AR, FR, DE, ES, IT

## HTML DSL i18n Macros

```nim
import nimleptos

registerI18nCatalog("locales/app.json")  # compile-time key validation

let cfg = createI18n(cat, "en")

let node = buildHtml(cfg):
  el("h1"): t"hello"           # shorthand: translate "hello"
  el("p"): tp"greeting"         # shorthand with default params
  el("span"): t(cfg, "world")   # explicit call syntax
```

Compile-time validation: if a key does not exist in the default catalog, compilation fails with a clear error.

## API Reference

### Catalog
- `loadCatalog(path)` — load from JSON file (native only)
- `emptyCatalog()` — create empty catalog
- `addTranslation(cat, locale, key, msg)` — add single message
- `getMessage(cat, locale, key)` — get message with fallback
- `mergeCatalogs(a, b)` — combine two catalogs

### i18n
- `createI18n(catalog, initialLocale)` — create config with new signal
- `createI18n(catalog, getter, setter)` — create config with existing signal
- `t(cfg, key)` — reactive translation getter
- `tp(cfg, key, paramsFn)` — reactive translation with interpolation
- `translate(cfg, key)` — non-reactive single-shot translation
- `setLocale(cfg, locale)` — change locale
- `useLocale(cfg)` — get locale getter

### Interpolation
- `interp.str(v)` — string value
- `interp.intv(v)` — integer value
- `interp.floatv(v)` — float value
- `interpolate(template, params)` — replace `{key}` placeholders
