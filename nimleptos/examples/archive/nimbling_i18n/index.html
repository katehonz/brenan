How it works:

  • JSON catalog is loaded by JS and passed to WASM via addTranslation() calls
  • All elements with data-i18n-key are registered for auto-update
  • Clicking a locale button calls wasm.setLocale()
  • WASM notifies JS via registerOnLocaleChange callback
  • JS updates DOM text nodes with wasm.translate() / wasm.translateWithParams()
